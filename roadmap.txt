Steps & Roadmap :

1. Game Engine Core :
   [x] Deck representation and Fisher-Yates shuffle
   [x] Player hand, won cards tracking, and dynamic players management
   [x] Exact legal moves validation via Bitmask DP (is_legal, Ace 1/11 handling)
   [x] Exhaustive move generation (gen_card_moves, gen_all_moves)
   [x] Play legal move execution (play_move, drop on table, Tablic detection)
   [x] Comprehensive unit test suite with AddressSanitizer/UBSan
   [x] Full Game Loop:
        - Turn-by-turn player alternation (run_round)
        - Successive card deals : deal_next_hand (3x redistribution after setup)
        - Award remaining table cards to last capturing player (award_remaining_table_cards)
        - Generic evaluator interface (t_evaluator, s_cte_round_config)
   [x] Round scoring & match management:
        - Summing captured card points (compute_round_score)
        - Majority cards bonus (+3 points for >= 27 cards, 0 if 26/26 tie)
        - Tablic bonus points (+1 each)
        - Configurable winning threshold (run_match, s_cte_match)
   [x] 3 & 4 player support
   [x] Team mode for 4 players
   [x] cli Configurable AI evaluation function (per-player strategies)
   [x] separate backend (move choosing) and frontend (cli/tui/gui) completely
   [x] split files & headers (cleanup)

2. Interface :
   [x] Interactive CLI (game board display, human input, AI vs human / 2 players / AI vs AI, Unicode & ASCII styles)
   [x] TUI (ncurses minimalist with color pairs, arrows navigation & dynamic board)
   [ ] Ncurses fancier TUI 
   [ ] AI x AI screensaver mode
   [ ] Potential GUI (Raylib, SDL, or Web wrapper)

3. AI & Search :
   [x] Generic evaluator interface (t_evaluator / s_cte_round_config) + eval_random
   [x] Heuristic & baseline evaluators:
        - [x] The dummy : always try to drop a card when possible (eval_dumb)
        - [x] Greedy point capture maximization (eval_greedy)
        - [x] Pure move scoring function decoupled from state (score_move)
   [x] Minimax & Tree Search Engine (minmax.h / minmax.c):
        - [x] Compact 64-byte L1 cache snapshot (s_cte_pos)
        - [x] Alpha-Beta pruning search (search_best_move)
        - [x] Cheater / Oracle lookahead evaluator (eval_cheater)
   [ ] Advanced Search & Optimization:
        - [ ] Move ordering (score_move heuristic & PV move first)
        - [ ] Principal Variation (PV) caching & turn reuse
        - [ ] Transposition Table (TT) with Zobrist hashing
        - [ ] Fair AI: Perfect Information Monte Carlo (PIMC determinization)
        - [ ] Monte Carlo Tree Search (MCTS)

4. HPC & Architecture Optimizations (Bitboards & SIMD) :
   [ ] Backend-agnostic engine abstraction layer:
        - Define abstract engine interface (state, move generator, move applicator, evaluator)
        - Seamless pluggability between Array backend, Bitboard backend, and SIMD backend
   [ ] Reentrant game state:
        - Encapsulate global deck & table into reentrant struct (s_cte_game)
        - Eliminate dynamic heap allocations during search
   [ ] 64-bit Bitboard backend:
        - Represent 52-card sets as `uint64_t` bitboards (table, hand, won cards)
        - Fast bitwise subset sum / exact partition using BMI2 (`POPCNT`, `TZCNT`, `BLSR`, `PDEP`)
   [ ] SIMD Vectorization backend (AVX2 / AVX-512 / NEON / MIPPv2):
        - Inter-game batch vectorization (Structure of Arrays - SoA)
        - Parallel batch rollouts and SIMD-accelerated linear evaluations
   [ ] Multithreading:
        - Root move parallelization & Lazy SMP with lock-free TT
        - Mass self-play game simulation for reinforcement learning
